Under the hood

What actually carries across screens

The exports arrived as nine unlinked pages whose buttons ended in alert(). A shared shell wires them together without editing the wireframes themselves.

Shared session state

Persona, credit balance, bookings, escrow release and dispute outcome live in sessionStorage. Book a mentor in step 3 and the booking appears on the founder workspace and on the mentor's inbound queue.

Real navigation

Every href="#" nav item — Gateway, Founder Deck, Advisory Board, Governance, Audit Ledger — now resolves to the screen it names. Links with no destination in scope say so instead of doing nothing.

Fixed: the empty vault tab

Two consoles shipped a “Pitch Decks & Vault” tab with no matching view, so selecting it blanked the workspace. The shell builds the missing view, styled to match.

Non-blocking feedback

Blocking alert() dialogs are replaced by toasts that name the next step and link to the screen where it happens — so the walkthrough never dead-ends.
