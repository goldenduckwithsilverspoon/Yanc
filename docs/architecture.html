Core system architecture
◈ RBAC security engine

Resolves persona → permission set on every request. Decides which directory rows, decks and admin consoles a session may even see.

6 personas · 7 console roles
₹ Escrow & credit ledger

Single source of truth for money. Holds session funds from checkout to release, and converts member credits at a fixed rate.

1 credit = ₹100 · dual-key release
⇄ Event-driven PubSub

Every booking, deck view, escrow move and admin action is emitted as an event — which is what makes the audit log immutable and replayable.

append-only · SHA-256 chained
⚖ Advisory board governance

Advisor vetting, SLA enforcement, dispute remediation and multi-sig custody policy for anything that overrides a bilateral signature.

quorum 4 of 5 · 24h approval SLA

The rules the ledger enforces

These are the constants every screen in the demo is priced and gated against.

Credit rate
1 credit = ₹100
Members spend 1 credit for a 45m online call, 2 for a 60m offline session.
Non-member pricing
₹500 / ₹1,500
Direct INR checkout, 100% held in escrow before the session is confirmed.
Response SLA
48 hours
Mentor must accept, reschedule or decline before the hold auto-reverses.
Release protocol
Dual-key
Founder's 4-digit venue code plus advisor confirmation. Override needs quorum.
