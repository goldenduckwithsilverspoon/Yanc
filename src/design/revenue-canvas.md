## Brand & Style

The design system establishes a high-performance, modern SaaS workspace tailored for revenue, marketing, and customer operations teams. It merges the trustworthy rigor of enterprise software with the agile clarity of modern venture tech. 

The aesthetic is grounded in **Corporate Modern** with sharp visual precision: crisp white card surfaces framed by muted slate borders, layered over soft neutral canvas tones, and punctuated by authoritative deep navy and vibrant coral-orange accents. 

The interface evokes confidence, operational efficiency, and effortless control. Information density remains high without feeling cluttered, using clear structural hierarchy, subtle depth transitions, and deliberate micro-interactions to guide user attention to critical metrics and action items.

## Colors

The color palette centers on a high-contrast relationship between vibrant energetic coral-orange, authoritative deep corporate navies, and serene slate neutrals.

- **Primary (`#ff5c35`)**: The core catalyst color, reserved for key conversion actions, focus states, and essential milestones.
- **Secondary (`#001e3d`)**: The structural anchor, providing maximum legibility for primary navigation, high-level page titles, and prominent enterprise indicators.
- **Tertiary (`#2d3e50`)**: Secondary headers, inactive navigation states, table column headers, and structural UI elements.
- **Neutral (`#66788a`)**: Supporting metadata, tooltips, secondary labels, and descriptive body copy.
- **Canvas & Surface Backgrounds**: The page foundation sits on `slate-bg` (`#f5f8fa`), while elevated modules and cards rest on pure `#ffffff`, separated by structural borders in `#cbd6e2` and `#dfe3eb`.
- **Feedback Accents**: Purpose-built semantic shades (`success-emerald`, `danger-rose`, `warning-amber`) provide instant operational recognition for metric deltas and badge indicators.

## Typography

Typography relies on **Plus Jakarta Sans** across all roles, delivering high geometric clarity, open counters, and contemporary legibility essential for dense enterprise dashboards.

- **Numerics & Data Density**: Metric display scales use tabular figures and negative letter-spacing for tight horizontal alignment in dashboards and analytical reports.
- **Microcopy**: Badges, table headers, and category tags leverage uppercase or high-weight medium styling at `11px` to `13px` with positive tracking to optimize scan speed.
- **Hierarchy Control**: High-level page headings use heavy weights (`700` and `600`) paired with deep navy (`#001e3d`), creating immediate context before transitioning to slate-tinted neutral body text.

## Layout & Spacing

The layout model combines an operational shell with a 12-column responsive fluid grid.

- **The Shell**: A primary top navigation bar (`64px` height) anchors the workspace, optionally joined by a secondary horizontal sub-header (`48px` height) for views requiring granular filtering, views switching, and tabbed sub-modules.
- **Content Canvas**: Maximum container width is constrained to `1600px` for optimal data visualization and metric distribution, centering gracefully on ultra-wide screens.
- **Grid Architecture**:
  - **Desktop (≥1024px)**: 12-column grid with `32px` margins and `24px` gutters.
  - **Tablet (768px – 1023px)**: 8-column grid with `24px` margins and `16px` gutters. Panels wrap into dynamic dual-column stacks.
  - **Mobile (<768px)**: 4-column grid with `16px` margins and `12px` gutters. Data cards and metrics transition into single-column vertical stacks, and tables enable horizontal sticky scrolling.

## Elevation & Depth

This design system uses a tactile, low-elevation philosophy centered on **crisp slate outlines and soft ambient shadows**. Deep dramatic drops are avoided to preserve interface clarity and eliminate visual noise.

- **Flat / Ground Level (`z-0`)**: The application canvas rests on `#f5f8fa`.
- **Card Tier (`z-1`)**: Standard metric tiles and data tables sit on pure `#ffffff` with a `1px solid #cbd6e2` border and an ultra-subtle ambient shadow: `0 1px 3px 0 rgba(0, 30, 61, 0.04), 0 1px 2px -1px rgba(0, 30, 61, 0.02)`.
- **Card Hover / Interactive Tier (`z-2`)**: Active cards and clickable list items shift to a refined lift: `0 4px 12px -2px rgba(0, 30, 61, 0.08), 0 2px 6px -1px rgba(0, 30, 61, 0.04)`, with border transition to `#cbd6e2`.
- **Dropdown & Flyout Tier (`z-3`)**: Select menus, date-pickers, and action menus: `0 10px 25px -5px rgba(0, 30, 61, 0.12), 0 8px 10px -6px rgba(0, 30, 61, 0.04)`.
- **Modal & Drawer Overlay (`z-4`)**: Flyout drawers and modal dialogs: `0 20px 35px -5px rgba(0, 30, 61, 0.2), 0 10px 15px -5px rgba(0, 30, 61, 0.08)`, paired with a tinted navy backdrop overlay (`rgba(0, 30, 61, 0.4)`).

## Shapes

The design system employs a refined **Soft** shape language (`roundedness: 1`). Elements maintain precise structural cohesion without appearing blocky or overly playful.

- **Inputs, Buttons, and Table Headers**: `4px` (`rounded-sm`) to `6px` (`rounded-md`), ensuring sharp alignment alongside data grids and dense form fields.
- **Cards, Modals, and Modules**: `8px` (`rounded-lg`), providing gentle separation while retaining strong architectural lines.
- **Badges, Trend Indicators, and User Avatars**: Fully rounded pill shapes (`9999px`) to create clear contrast between structural layout boxes and fluid status indicators.

## Components

### Buttons
- **Primary**: Solid coral background (`#ff5c35`), white text, semi-bold weight. Hover transitions to `#e5431b` with a subtle elevation shift. Focus uses an outer coral ring: `0 0 0 3px rgba(255, 92, 53, 0.25)`.
- **Secondary**: Crisp white background, `1px solid #cbd6e2`, secondary navy text (`#001e3d`). Hover activates a soft slate tint (`#f5f8fa`) and sharp border (`#2d3e50`).
- **Tertiary / Ghost**: Transparent background, slate-navy text (`#2d3e50`). Hover reveals `#dfe3eb`.
- **Destructive**: Solid danger rose (`#f2545b`) or secondary border with `#f2545b` label.

### Form Inputs & Select Fields
- Base height is fixed at `38px` for data-density alignment.
- Crisp white background bordered by `1px solid #cbd6e2` with `6px` corner radius.
- Active focus state sharpens the border to `#001e3d` with an ambient navy glow: `0 0 0 3px rgba(0, 30, 61, 0.08)`.
- Placeholder text uses `#66788a` at `14px`.

### Metric KPI Cards
- White surface, `1px solid #cbd6e2`, `8px` border radius, and `20px` internal padding.
- Includes category metadata label at top, prominent metric value in `metric-val` typography, and an inline pill badge representing percentage trend deltas.
- Upward trends: `#00a389` text over `#e6f8f5` background with an upward arrow.
- Downward trends: `#f2545b` text over `#fdebed` background with a downward arrow.

### Data Tables
- Encased in a card shell with a subtle header bar containing search and batch action controls.
- Table headers: `#f5f8fa` background, `11px` tracking uppercase, semi-bold tertiary navy text (`#2d3e50`), border bottom `1px solid #dfe3eb`.
- Table rows: White background, alternating hover state (`#f5f8fa`), `48px` default row height for high scannability, cells separated by `1px solid #dfe3eb`.
- Row selection integrates custom checkbox components with full row highlighting in soft coral tint (`#fff1ed`).

### Badges & Status Pills
- Compact height (`22px`), `9999px` border radius, padding `2px 8px`, `11px` semi-bold text.
- Status mappings: Active/Live (Emerald), In Review/Pending (Amber), At Risk/Critical (Danger Rose), Draft/Archived (Slate Neutral).

### Navigation Bars & Sub-Headers
- **Top Bar**: Deep corporate navy background (`#001e3d`) or crisp white with bottom border (`#cbd6e2`). Integrates global search, quick-action launcher in coral (`#ff5c35`), notification center, and user profile avatar.
- **Sub-Header**: Pure white background with horizontal tabbed navigation. Active tab is indicated by an authoritative coral bottom border (`2px solid #ff5c35`) and bold secondary navy text.
